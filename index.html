⚙ 设置

账号 / 套餐
账号 Key 保存时自动送入本机加密库(DPAPI 加密,磁盘无明文),浏览器里只保留加密引用,不会上传第三方。 Key 获取:全球站 z.ai 控制台, 国内站 bigmodel.cn 控制台。
网络
一般无需手动配置:由 http://127.0.0.1:8788/?live=1 打开时会自动填好。 也可以用任何 ?url= 风格代理,地址里的 {url} 会被替换成编码后的接口地址。 Key 留空时,本地服务会自动注入 key.txt 中的密钥。
API Key(加密存储在本机)
密钥经 Windows DPAPI 加密写入 key.enc(绑定当前 Windows 用户,磁盘无明文), 由本地服务注入请求头,所有浏览器通用。 优先级:ZAI_API_KEY 环境变量 > key.enc > key.txt。
